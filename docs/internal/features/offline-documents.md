# Offline Documents (PWA)

Complete guide to Offline Documents in the NTG School Management System (SMS).

## 📋 Overview

The portal includes an **Offline Documents** page intended for accessing documents when connectivity is limited.

{% @mermaid/diagram content="graph TB
A[Offline Documents] --> B[View Saved Items]
B --> C[Open Document]
C --> D[Use Offline (when available)]
E[PWA] --> A" %}

## 📄 Accessing Offline Documents

**Steps:**

1. Go to **Offline Documents**
2. Review available saved/offline items (as shown by the portal)
3. Open a document to view

## 🆘 Notes

Offline availability depends on:

- Browser/PWA capabilities
- What content has been saved/downloaded for offline use
