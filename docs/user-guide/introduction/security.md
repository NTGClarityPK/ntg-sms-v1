# 🔐 Security

## Account Security

* Use a strong, unique password
* Never share your password with colleagues
* Change your password if you suspect it is known to others
* Logout when you finish working

## Session Management

* Always logout when leaving a shared or public device
* Do not leave the portal unattended on a signed-in device
* Close the browser on shared computers

## PIN Access

Where device PIN login is enabled, the PIN is specific to that device and is a convenience on top of your account — not a replacement for your password. Remove the PIN if the device changes hands.

## Access Control

* You only see the modules your role permits
* Some modules also depend on your school's subscription plan
* Report unexpected access, missing access, or data you should not be able to see to your administrator

## Data Handling

* Downloaded PDFs (report cards, challans, certificates) contain personal data — store and share them carefully
* Data export ZIP files are password protected; keep the backup password safe and store the file securely
* Follow your school's policy for sharing student information with parents

## Reporting a Concern

Contact your school administrator immediately if you notice:

* An account that should no longer have access
* Records changing unexpectedly
* Suspicious login notifications
