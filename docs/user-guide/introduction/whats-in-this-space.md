# 📚 What's in This Space

This documentation space covers:

* **📖 User Manual** - Complete guide for school staff, parents, and students
* **🎯 Feature Guides** - Detailed guides for each portal module
* **🗓️ Operational Procedures** - Step-by-step instructions for daily school operations
* **🆘 Troubleshooting** - Common issues and solutions

## Who this documentation is for

**School Owners / Administrators:**

* 🏢 **School Admin / Principal / Academic Coordinator** - Configure the school, manage academic structure, oversee operations, and access reports

**School Staff:**

* 👨‍💼 **Administrative Staff** - Support operational workflows based on assigned permissions
* 👨‍🏫 **Teachers** - Attendance, assessments, behavioural entries, timetable views
* 🧑‍⚕️ **Guidance Counselor** - Behavioural modules and related reporting

**Parents & Students:**

* 👨‍👩‍👧‍👦 **Parents** - Child context, attendance, requests, notifications, uniform requests
* 🎓 **Students** - Timetable, attendance, results, and notifications

## What the system helps you manage

* 🏢 School and branch setup
* 👥 Users, roles, and permission-based access
* 🎓 Students, parents, and staff operations
* 🗓️ Timetables, schedules, and conflict management
* ✅ Attendance and attendance history
* 📝 Assessments, grades, and statistics
* ⭐ Behavioural tracking
* 🔔 Notifications and messaging
* 📚 Library access
* 👕 Inventory and uniform requests
* 📊 Reports and results
* 💵 Fee management and billing
* 🏆 Certificates and ID cards
* ⚙️ Settings and configuration
