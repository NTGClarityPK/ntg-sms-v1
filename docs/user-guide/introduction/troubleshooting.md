# Troubleshooting (Docs & Portal Basics)

| Problem | What to try |
|---------|-------------|
| Cannot see a menu item | Check role permissions and subscription plan features in Settings → Permissions / Billing |
| Wrong school data | Confirm the selected **branch** in the header |
| Wrong language | Use the language control in the top bar, or ask admin to set school default in Settings → Business Information |
| Page empty after login | Confirm academic year is active and you have a role on the branch |

Feature-specific troubleshooting lives at the bottom of each feature page.
