# Quick Start

## For School Admin / Principal / Academic Coordinator

1. Start with the **User Manual** — first login, navigation, and how permissions work
2. Go to **Settings** — configure academic years, academic structure, schedule, assessments, fees, integrations, and permissions
3. Set up **Academic Structure** — create class sections and map teachers
4. Review **Operations** — attendance, assessments, timetable, events, notifications, reports, fees

## For Teachers

1. Start with the **User Manual** — portal navigation and role visibility
2. Use **My Schedule** / Timetable
3. Use **Assessments** / **My Assessments** where permitted
4. Use **Attendance** where permitted
5. Use **Behavioural** where permitted

## For Parents

1. Login and select branch if prompted
2. Use **My Children** for child context
3. Raise **Leave** / **Early Departure** requests
4. Check **Notifications**
5. Use **Uniform Request** where inventory is enabled

## For Students

1. Login and open the student portal views
2. View timetable, attendance, and grades where enabled
3. Check notifications
