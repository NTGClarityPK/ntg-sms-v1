# 🚀 Quick Start

## 🏢 For School Admin / Principal / Academic Coordinator

1. Start with the [📖 User Manual](../user-manual/README.md) - first login, navigation, and how permissions work
2. Configure [⚙️ Settings](../features/settings-and-configuration.md) - business information, academic years, schedule, assessment, fees, integrations, permissions
3. Build your [🎓 Students](../features/students.md) and [👨‍🏫 Staff](../features/staff.md) records
4. Set up [👥 User Roles](../features/user-roles.md) so each role sees the right modules
5. Review operations - [✅ Attendance](../features/attendance.md), [📝 Assessments](../features/assessments.md), [🕐 Timetable](../features/timetable-and-schedule.md), [📊 Reports](../features/reports.md)

## 👨‍🏫 For Teachers (Class Teacher / Subject Teacher)

1. Start with the [📖 User Manual](../user-manual/README.md) - portal navigation and role visibility
2. Use [🕐 My Schedule](../features/timetable-and-schedule.md) - view your teaching schedule
3. Use [📝 Assessments](../features/assessments.md) - create assessments and enter grades where permitted
4. Use [✅ Attendance](../features/attendance.md) - mark and review attendance
5. Use [⭐ Behavioural](../features/behavioural.md) - submit behavioural assessments where permitted

## 👨‍👩‍👧‍👦 For Parents

1. Start with the [📖 User Manual](../user-manual/README.md) - login, branch selection, and notifications
2. Open **My Children** to switch child context
3. Use [🌴 Leave Requests](../features/leaves.md) - raise and track leave
4. Use [🚶 Early Departure](../features/early-departure.md) - request early collection
5. Check [🔔 Notifications](../features/notifications.md) - track updates and mark as read
6. Use [👕 Uniform Request](../features/inventory-uniforms.md) where inventory is enabled

## 🎓 For Students

1. Start with the [📖 User Manual](../user-manual/README.md) - login and navigation
2. Use [🕐 My Timetable](../features/timetable-and-schedule.md) - view your timetable
3. View [✅ Attendance](../features/attendance.md) where available
4. View [🥇 Results](../features/results.md) when published
5. Check [🔔 Notifications](../features/notifications.md) - track updates

## 🌐 First-Time Tips

* Confirm the **branch** shown in the header matches where you work
* Set your language from the top-bar language button, or follow the school default
* If a menu item is missing, it is usually a role permission or plan entitlement — see [🆘 Troubleshooting](troubleshooting.md)
