# 🔄 Documentation Updates

This documentation is updated as NTG Alma evolves:

* ✨ New modules and workflows
* 🐛 Bug fixes and behaviour changes
* 🎨 UX improvements and performance work
* 📝 Clearer instructions based on user feedback

## How updates reach this space

Pages are maintained in the product repository under `docs/user-guide/` and published to GitBook automatically. That means a documentation update ships with the feature it describes, rather than being copied over afterwards.

## For maintainers

When a feature changes:

1. Update the matching page under `features/`
2. Add new pages to `SUMMARY.md` and the [Features](../features/README.md) index
3. Keep user-facing wording free of internal technical detail
4. Use British English and the product name **NTG Alma**
