# Documentation Structure

Source of truth in the repository:

```text
docs/user-guide/
├── README.md                 # This space landing page
├── SUMMARY.md                # GitBook sidebar TOC
├── introduction/             # How to use these docs
├── user-manual/              # Role-based getting started
└── features/                 # One Markdown file per feature
```

Each GitBook page maps to exactly one `.md` file. When you add a feature page, also add it to `SUMMARY.md`.
