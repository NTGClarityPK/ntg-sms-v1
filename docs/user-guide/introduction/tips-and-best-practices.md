# 💡 Tips & Best Practices

## 🏗️ Setup

* Configure Settings before starting day-to-day operations
* Keep exactly one **active** academic year
* Complete the academic structure (levels, classes, sections, subjects) before building timetables
* Assign grade templates to classes before entering assessment marks

## 🗓️ Daily Operations

* Mark attendance promptly each day
* Enter assessment marks as work is graded, rather than in one batch at term end
* Act on notifications quickly so requests do not expire
* Communicate delays or changes to parents through the portal

## 👥 Data Quality

* Use bulk import for large cohorts instead of manual entry
* Keep student photos and contact details current before generating ID cards
* Review parent associations at the start of each year
* Set the student Google account email before pulling Classroom grades

## 💵 Fees

* Create templates once and reuse them each month
* Use bulk generation for whole classes
* Reserve individual adjustments for genuine exceptions such as mid-month joiners
* Download and share challans before the due date

## 🥇 Results

* Check **Marks readiness** before publishing a term card
* Download a sample PDF to review the layout
* Keep the class teacher comment factual; it cannot be edited after publish
* Publish only when the card is ready for parents to download under **My Child**

## 🛡️ Access Control

* Follow the principle of least privilege when assigning roles
* Review role assignments each term
* Test a role's access after changing its permissions
* Remove access promptly when staff leave

## 💾 Records & Backups

* Take a data export before major changes such as year-end promotion
* Store backup ZIP files securely and remember the backup password
* Keep downloaded personal data (report cards, challans) only as long as needed
