# 📝 Quick Reference

## Common Tasks

**Daily Opening:**

1. Login to the portal
2. Confirm the correct branch in the header
3. Check the dashboard
4. Review notifications

**Marking Attendance:**

1. Go to **Attendance**
2. Select class and date
3. Mark students
4. Save

**Creating an Assessment:**

1. Go to **Assessments**
2. Click the create action
3. Select class, subject, and assessment type
4. Set total marks and date
5. Save, then enter grades from **Grade Entry**

**Generating Fee Challans:**

1. Go to **Fees → Challan management**
2. Select class and month
3. Click **Generate challans**
4. Download and share PDFs

**Publishing Results:**

1. Go to **Results** and select the class
2. Create each required draft card
3. Add the class teacher comment
4. Publish for parents; parents download it under **My Child**

**Raising a Leave Request (Parent):**

1. Go to **Leaves**
2. Select the child and dates
3. Add a reason
4. Submit and track the approval

**Changing Your Language:**

1. Open the language button in the top bar
2. Choose a language, or **Use school default**

## Where Things Live

| Task | Location |
| --- | --- |
| School identity and default language | Settings → Business Information |
| Academic years | Settings → Academic Years |
| School days, timings, holidays | Settings → Schedule |
| Assessment types and grade templates | Settings → Assessment |
| Fee templates and challan settings | Settings → Fees |
| Google Classroom and rubric presets | Settings → Integrations |
| Role permissions | Settings → Permissions |
| Data backup | Settings → Data export |
