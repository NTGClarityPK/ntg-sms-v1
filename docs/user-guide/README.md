# Introduction

Welcome to the **NTG Alma** user documentation.

This space helps school administrators, teachers, parents, and students use the Alma portal day to day.

## What's in this space

- **Introduction** — how to find your way around these docs
- **User Manual** — role-based getting started and setup order
- **Features** — one guide per module (Settings, Fees, Students, Assessments, and more)

## Quick start

| Role | Start here |
|------|------------|
| School admin / Principal | [User Manual](user-manual/README.md) → [Settings](features/settings-and-configuration.md) |
| Teachers | [Quick Start](introduction/quick-start.md) → Attendance, Assessments, Timetable |
| Parents | [Quick Start](introduction/quick-start.md) → children views, leave, notifications |
| Students | [Quick Start](introduction/quick-start.md) → timetable, attendance, grades |

## Related documentation

Technical setup, schema, and deployment live in the **private** [Developer Guide](https://ntg-1.gitbook.io/ntg-alma-dev-docs/) (team only).

## Documentation updates

Docs are maintained in the product repository under `docs/user-guide/` and published via GitBook Git Sync. When a feature ships, update the matching page under `features/` (and `SUMMARY.md` if you add a new page).
