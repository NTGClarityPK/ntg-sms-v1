## 📝 Quick Reference

### Common Tasks

**Daily Opening:**

1. Login to the portal
2. Confirm the correct branch in the header
3. Check the dashboard
4. Review notifications

**Marking Attendance:**

1. Go to Attendance
2. Select class and date
3. Mark students
4. Save

**Generating Challans:**

1. Go to Fees → Challan management
2. Select class and month
3. Generate challans
4. Download and share PDFs

**Publishing Results:**

1. Go to Results and select the class
2. Create each required draft card
3. Add the class teacher comment
4. Publish for parents; parents download it under **My Child**

## 🆘 Troubleshooting

### Common Issues

**Cannot Login:**

* Verify email and password
* Check your internet connection
* Contact your school administrator if locked out

**Menu Item Missing:**

* Your role may not have permission
* The module may not be included in your plan
* Confirm the selected branch

**Wrong School Data:**

* Confirm the branch shown in the header
* Confirm the active academic year

**Portal in the Wrong Language:**

* Use the language button in the top bar
* Or ask an admin to set the school default in Settings → Business Information

See [Troubleshooting](introduction/troubleshooting.md) for more solutions.

## 💡 Tips & Best Practices

### Setup

* Configure Settings before starting day-to-day operations
* Keep exactly one **active** academic year
* Complete academic structure before timetables

### Daily Operations

* Mark attendance promptly each day
* Enter assessment marks as they are graded
* Act on notifications quickly

### Data Quality

* Use bulk import for large cohorts
* Keep student photos and contact details current
* Review parent associations regularly

## 📱 Mobile Usage

The portal works on mobile devices:

* Open the browser on your phone or tablet
* Navigate to your school portal URL
* Login with your credentials
* Install as an app for offline document access where enabled

## 🔐 Security

### Account Security

* Use strong passwords
* Never share your password
* Logout when finished

### Session Management

* Always logout when leaving a shared device
* Do not leave the portal unattended

### Access Control

* Understand your role and permissions
* Report access issues to your administrator
