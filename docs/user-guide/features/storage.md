# 🗄️ Storage

Complete guide to the Storage admin page in NTG Alma.

## 📋 Overview

The Storage page provides an admin-facing view related to storage usage and management for the current branch/tenant context.

{% @mermaid/diagram content="graph TB
A[Storage] --> B[View Usage]
A --> C[Admin Actions (where enabled)]
B --> D[Branch Context]" %}

## 🗄️ Accessing Storage

**Steps:**

1. Go to **Admin → Storage**
2. Review storage information displayed for the current context

## 🆘 Troubleshooting

**Storage page not visible:**

- Storage is restricted to roles with admin permissions
