# 📨 Messages

Realtime school messaging — one-to-one chats and role-based broadcasts.

## 📋 Overview

**Path:** Sidebar → **Messages**

Two-pane layout: conversation list on the left, chat on the right. There are no separate module tabs.

| Filter | Meaning |
| --- | --- |
| **All** | Every conversation |
| **Unread** | Conversations with unread messages |
| **Read** | No unread messages |

Search filters the conversation list. Opening a chat marks its messages as read. New messages in the open chat arrive in real time; the list refreshes about every 20 seconds.

Staff messaging roles include class/subject teacher, principal, school admin, academic coordinator, guidance counselor, admin assistant, and super admin. Students and parents send or reply only when **Settings → Communication** allows teacher–student or teacher–parent messaging both ways.

---

## 💬 Conversation types

| Type | Who can start |
| --- | --- |
| **One-to-one** | Permitted roles (direction rules apply for students/parents) |
| **Broadcast to class** | Staff with messaging access |
| **School broadcast** | School admin (all or specific branches); principal / admin assistant for current branch when delegated in communication settings |

School broadcast recipient roles can include students, parents, teaching roles, coordinators, principal, school admin, admin assistant, and super admin.

---

## 📖 Read state

- Opening a conversation marks messages **read** for you.
- Unread counts drive the **Unread** filter and badges.
- There are **no** sender-facing “seen” ticks.

---

## 🗑️ Deleting

- Delete **your own** message for everyone.
- **Clear chat** and **Delete conversation** apply to **your** copy of the thread (per-user), even if confirmation text sounds global.

---

## 💡 Tips & Best Practices

- Prefer class broadcast for announcements that belong to one class section.
- Check Communication settings before expecting student or parent replies.

---

## 🆘 Troubleshooting

**Cannot message a parent or student:** Ask an admin to allow two-way Teacher–Parent or Teacher–Student communication.

**Broadcast options missing:** Your role may only allow one-to-one, or branch broadcast is not delegated.
