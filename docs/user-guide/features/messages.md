# 📨 Messages

Complete guide to the Messages module entry in NTG Alma.

## 📋 Overview

Messages is the portal entry point for school communication workflows available to your role and permissions.

{% @mermaid/diagram content="graph TB
A[Messages] --> B[View Conversations]
A --> C[Send Messages]
C --> D[Recipients (Role-based)]
D --> E[Notifications (where enabled)]" %}

## 💬 Accessing Messages

**Steps:**

1. Go to **Messages**
2. Review available message views and conversations

## 🆘 Notes

Message availability and actions depend on:

- Your role permissions
- Branch context
- Communication direction settings (configured by admins)
