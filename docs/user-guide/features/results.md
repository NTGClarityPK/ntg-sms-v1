# 🥇 Results

Short guide for staff who generate report cards and for parents who download published ones.

## 📋 Overview

Results combine **assessment marks** into PDF report cards. Staff work on the **Results** page; parents see **published** cards under **My Child**.

| Audience | Where | What they can do |
| --- | --- | --- |
| Teachers / coordinators / admins with edit access | **Academics → Results** | Filters, draft cards, remarks, publish, PDF / ZIP download |
| Principals and view-only roles | **Results** | View and download PDFs (no draft / publish) |
| Parents / guardians | **My Child** | Download **published** cards only |

There is **no** email or SMS send from Results in the portal today. Share PDFs yourself (download, print, or WhatsApp).

---

## 📑 Report kinds and phases

| Report kind | When the phase control appears | Typical use |
| --- | --- | --- |
| **Term report** | Yes — **Status**: Interim / Mid-term / Final | Formal term cards |
| **Annual report** | No (treated as Final internally) | End-of-year summary PDF |
| **Progress report** | No | Informal updates; each new card gets a sequence number (Progress 1, 2, …) |

Phase mainly labels the card and PDF banner. Marks for the class section and academic year are used together — the portal does not split assessments by Interim vs Mid-term vs Final when building the snapshot.

## 🧑‍🏫 Staff: Results page

**Path:** Sidebar → **Academics → Results**

Class teachers only see class sections they own; other staff see available sections (capped in the list).

### Filters

1. **Class section** (if more than one is available)
2. **Academic year** (active year, read-only)
3. **Report type** — Term / Annual / Progress
4. **Status** (term report only) — Interim / Mid-term / Final

### What you see after selecting a class

| Section | Content |
| --- | --- |
| **Marks readiness** (term report) | Whether every student has grades for all in-scope assessments, or how many students are missing at least one |
| **Top students (overall %)** | Up to three students with the highest overall percentage |
| **PDF layout** | **Minimal** or **Modern** (overrides the school default for this session) |
| **Student table** | Student, Overall %, Report card status, Actions |

Bulk ZIP (term report + edit access only): **Download all Interim/Mid-term/Final (ZIP)** — **basic** PDFs only, **maximum 60 students** per request.

---

## 📄 PDF downloads

### Per student (Actions → Download PDF)

| Option | Notes |
| --- | --- |
| **Basic report** | One-page summary |
| **Detailed report** | Assessment breakdown; Final term and Annual detailed PDFs are two pages (mid-term + final combined) |

Layout: **Minimal** (print-friendly) or **Modern** (colour). Branch default lives under **Settings → Result reports** (school admin / principal / super admin).

### Bulk ZIP

- Term reports only
- Basic PDFs only
- Max **60** students
- Not available for Annual or Progress, and not for detailed PDFs

PDFs include subject marks, overall %, letter grades, and class teacher remarks when a card exists. Conduct is shown as a placeholder (—). Attendance is not pulled from the attendance module on these cards.

## 📝 Official cards (draft → publish)

Use cards when you want a **class teacher comment** and parent visibility on **My Child**.

| Status on table | Meaning |
| --- | --- |
| **Not generated** | No card yet — PDF still available from current marks |
| **Draft** | Card created; remarks can be edited |
| **Published** | Visible to parents; remarks locked |

### Steps

1. Actions → **Create draft card** (or **Update draft from latest marks** if a card already exists).
2. Actions → open remarks → enter **Class teacher comment** → Save.
3. Actions → **Publish for parents** → confirm.

There is **no** unpublish in the UI, **no** bulk create/publish, **no** comment templates, and **no** subject-teacher remarks field. Regenerating a card returns it to **Draft**.

---

## 👨‍👩‍👧 Parents: My Child

1. Open **My Child**.
2. Under each child, open **Published report cards**.
3. Download PDF (choose Minimal / Modern). Empty state: **No published report cards yet.**

Parents do not use the staff Results page for viewing.

---

## ⚙️ Settings: Result reports

**Settings → Result reports** (Appearance / Academic area in Settings):

- Default **PDF style** (Minimal / Modern)
- Progress — max assessments and window (days) — stored for the school; generation still uses the full class assessment set unless your school process limits what is entered

---

## 💡 Tips & Best Practices

- Check **Marks readiness** before publishing a term card.
- Download a sample PDF before sharing with parents.
- Prefer **Detailed** for parent–teacher meetings; use **Basic** or ZIP for quick class packs.
- Keep comments factual — they lock after publish.

---

## 🆘 Troubleshooting

**I cannot create or publish cards:** You need edit access (typically via assessment permissions). Principals may see Results but only download.

**Parent cannot see a card:** Status must be **Published**, and the parent must be linked to that student on **Mapping**.

**ZIP button missing:** Only for **Term report**, with edit access, and within the 60-student limit.

**Wrong layout:** Change **PDF layout** on the Results page, or the school default under **Settings → Result reports**.
