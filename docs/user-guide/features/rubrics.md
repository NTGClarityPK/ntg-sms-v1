# 📐 Rubrics

Structured criterion marks for assessments (for example Knowledge, Thinking, Application, Communication).

## 📋 Overview

| Task | Where |
| --- | --- |
| Manage presets | **Settings → Integrations** → **Rubrics** accordion |
| Attach / score | Assessment **Grade Entry** |

School admin / principal manage presets. Teachers need Assessment Rubrics **edit** to attach or edit rubrics on assessments.

---

## 📦 Presets

- Global presets (for example KTAC) and branch-created presets.
- Editing a **global** preset never changes the global record — Alma creates or updates a **branch override** and hides the matching global preset for that branch.
- Presets define category names, optional codes, and default marks (flexible starting points — not a fixed official total).

---

## 📝 On Grade Entry

1. **Attach a rubric**, choose a preset, adjust category marks if needed, create.
2. Save the student’s **base grade** first.
3. Expand the student row to enter criterion scores (expansion is blocked until the base grade exists).
4. Criterion scores update the displayed total.

### Google Classroom

If the assessment is linked to Google Classroom and Classroom has a rubric, that rubric is **read-only** in Alma and updates via **Pull grades**. See [🏫 Google Classroom](google-classroom.md).

---

## 💡 Tips & Best Practices

- Save grades before expanding rubric rows.
- Prefer branch overrides when your school’s mark weights differ from the global preset.

---

## 🆘 Troubleshooting

**Cannot expand rubric row:** Enter and save the base grade first.
