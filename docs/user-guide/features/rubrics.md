# Rubrics

Rubrics help mark assessments with structured criteria (for example Knowledge, Thinking, Application, Communication).

## Who this is for

- School Admin / Principal — manage presets
- Teachers with assessment edit permission — attach rubrics when grading in Alma

## Where to find it

- **Settings → Integrations → Rubric presets** (and related rubrics settings)
- Assessment **Grade Entry** when a rubric is attached

## What you can do

- Browse global presets (for example Ontario KTAC)
- Create or adjust branch presets and category default marks
- Attach an Alma rubric to an assessment that is **not** linked to Google Classroom
- Enter per-criterion scores on Grade Entry

## Google Classroom note

When an assessment is **linked to Google Classroom** and Classroom has a rubric, Google's rubric becomes the source of truth. The Alma rubric UI becomes read-only for that assessment. See [Google Classroom](google-classroom.md).
