# 🎧 In-app Support

Chat with the NTG support team from inside NTG Alma. Available to everyone signed in with a campus branch selected.

## 📋 Overview

Open **Support** from the Communication section in the sidebar, or use the headset button at the bottom-right of the portal. Unread replies from NTG are shared across your campus: when anyone on the branch opens a chat, the unread mark clears for everyone.

Support needs an internet connection. Offline, the page and floating button are hidden or blocked until you reconnect.

## 🚀 How to use it

1. Open **Support** (sidebar or headset button).
2. Select an existing chat, or start **New chat**.
3. Send text, images, files, voice notes, screenshots, or short screen recordings.
4. Wait for an NTG agent reply. Coverage banners show when support is offline or about to end for the day.
5. Monthly platform and operational minutes appear at the top of the page for awareness.

Closed chats stay in the list but look dimmed and cannot accept new messages.

## 💡 Tips & Best Practices

* Prefer one clear chat per issue with a short description in the first message.
* Attach a screenshot or short screen recording when reporting a portal problem.
* Campus unread is shared — opening a chat for your branch clears the red badge for colleagues on the same campus.
* The headset badge shows `1`–`9` or `9+`; Alma does not send browser push notifications for Support unread.

## 🆘 Troubleshooting

| Problem | What to try |
| --- | --- |
| No Support link or headset button | Check you are online and have a campus branch selected |
| Cannot send messages | Confirm the chat is still open (not closed) and you are online |
| Media will not play | Attachments can expire; ask Support to resend if needed |
| Coverage says offline | Use the “Back at …” time; you can still leave a message for when agents return |
