# 🏠 Dashboard

Role-based home screen after login — cards and panels that deep-link into everyday work.

## 📋 Overview

**Path:** Sidebar → **Dashboard** (under **School**, above the accordion groups)

| Who | What they see |
| --- | --- |
| School admin, principal, academic coordinator, admin assistant | Administrative overview |
| Class teacher, subject teacher, guidance counselor | Teacher overview |
| Parent / guardian | Parent overview |
| Student | Student overview |

If you have **more than one role**, use the **role switcher** in the Dashboard title bar. The choice is saved for your user and branch. Names appear in readable form (for example **School Admin**).

When a parent is **acting as a child**, Dashboard is hidden and child mode opens **My Assessments** instead.

---

## 💡 Tips & Best Practices

- Switch role on the Dashboard when you hold both teaching and admin roles so the right widgets appear.
- Use cards as shortcuts — they respect the same permissions as the sidebar.

---

## 🆘 Troubleshooting

**Dashboard missing while acting as a child:** Expected — leave child mode from the header switcher to return to the parent Dashboard.

**Wrong widgets:** Check the role switcher and your assigned roles under **Users**.
