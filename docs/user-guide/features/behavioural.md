# ⭐ Behavioural

Star ratings or framework-based category ratings by class section and month.

## 📋 Overview

**Path:** Sidebar → **Behavioural** (`/behavioral`)
Titles: **Behavioural Assessment** (desktop) / **Behavioural** (mobile)

Requires plan feature **Behavioural tracking** (**Pro** / **Enterprise**). Sidebar typically for class/subject teachers, guidance counselor, principal, school admin. Recording needs **edit** on the behavioural feature.

Tabs: **Matrix**, **Pending this month**, and **History**.

Which Matrix and Pending experience you see depends on the active system in Settings (star-based or framework-based).

---

## ⭐ Matrix (star-based)

Shown when the branch active system is **Star-based**.

1. Filter **Class section** and **Month**.
2. Rows = students; columns = configured attributes.
3. Rate each cell **1–5 stars**.
4. **Save** on that student’s row.

Default attributes (configurable): Discipline, Respect & Courtesy, Class Engagement, Work Habits, Extracurriculars.

---

## 🧩 Matrix (framework-based)

Shown when the branch active system is **Framework-based**.

1. Filter **Class section** and **Month**.
2. Rows = students; columns = framework categories (codes such as E/G/S/N appear after rating).
3. Open **Rate** / **Edit** on a student.
4. For each category, choose a scale level, review indicators, and add a comment when required.
5. **Save** to create or update that month’s rating.

---

## ⏳ Pending this month

**Star-based:** lists students in your assigned class sections who still lack an assessment for the current month.

**Framework-based:** choose a class section and month; lists students in that section without a framework rating for the month.

---

## 📜 History

Select a student to view a combined timeline of star and framework ratings, labelled by system and sorted by month. The same combined history also appears on the student report card under the behavioural averages section.

---

## ⚙️ Settings

**Settings → General → Behavioural assessment** (or **Settings → Behaviour**)

### Master options

- **Enable behavioural assessment**
- **Mandatory** (stored configuration — do not assume extra enforcement beyond what the UI shows)

### Rating system (one active at a time)

Choose **Star-based** or **Framework-based**. Switching preserves past ratings; new ratings use the active system.

**Star-based**

- Add / remove assessment attributes (for example Discipline, Respect & Courtesy)
- Teachers rate **1–5 stars** on those attributes

**Framework-based**

1. Clone **Ontario Learning Skills and Work Habits** (six categories, E/G/S/N) or create a blank framework
2. Customise your branch copy: name, comments required, rating scale, categories, and indicators
3. Switch to framework when at least one category exists

Global templates are read-only; only the branch-owned copy can be edited.

---

## 🆘 Troubleshooting

**Module missing:** Plan may not include behavioural tracking, or role lacks access.

**Pending list empty (star):** Either everyone is rated for the month, or you have no class-teacher sections assigned.

**Pending list empty (framework):** Select a section and month; empty means everyone in that section already has a rating.

**Framework matrix says no preset:** Configure and activate a branch framework under Settings → Behaviour.
