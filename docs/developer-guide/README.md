# Introduction

Welcome to the **NTG Alma** developer documentation.

This space is for developers, DevOps engineers, and system administrators working on the platform.

{% hint style="warning" %}
**Private space.** Do not publish secrets, live credentials, or detailed exploit steps for known issues. Prefer checklists and remediation pointers.
{% endhint %}

{% hint style="info" %}
**Note:** *NTG Alma* is the commercial name for the School Management System; internally you may still see *NTG SMS* or *ntg-sms-v1*.
{% endhint %}
